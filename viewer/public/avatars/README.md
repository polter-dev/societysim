# Avatars

Player portraits for the viewer: one per model, plus `human.webp` for visitor seats. They were generated with a Google Gemini image model, then center-cropped and resized to 512x512 webp (quality 82, no metadata). The filename is the model `name` from `configs/models.yaml` (for example `gpt-5-mini.webp`). The viewer uses them on seats, the leaderboard and model profiles (issues #302 and #297). If a model has no file, the UI should fall back to its current monogram medallion (wiring in #302). `amd-strix-gpt-oss-20b` reuses `amd-gpt-oss-20b.webp` (alias handled in the UI, #302). Vite copies `public/` into `dist/`, so they are served at `/avatars/<model>.webp`.
