# Contributing

Start with [AGENTS.md](AGENTS.md). It has the hard rules, commands and the ticket workflow.
The full plan is in [docs/PLAN.md](docs/PLAN.md) and the game rules are in [docs/RULES.md](docs/RULES.md).

To claim a ticket, pick a `status:ready` issue for your team and assign it to yourself with
the `status:in-progress` label. Branch as `issue-N-<slug>` from `origin/main`, then open a PR
whose body says `Closes #N`, with the `status:review` label.
